# Student Performance Analysis

### Maincrafts Data Science & Analytics Internship - Task 1

## Project Overview

This project analyzes the Student Performance dataset using Python. The task includes data exploration, data cleaning, basic analysis, and visualization of student performance.

## Tasks Completed

### Data Exploration and Cleaning

* Loaded the dataset using Pandas.
* Checked for missing values.
* Checked for duplicate records.
* Inspected dataset shape and data types.

### Data Analysis

* Calculated the average final grade (G3).
* Counted the number of students scoring above 15.
* Analyzed the relationship between study time and final grade.
* Compared average final grades by gender.

### Visualizations

* Histogram of final grades (G3).
* Scatter plot of study time vs final grade.
* Bar chart of average final grade by gender.

## Files Included

* `student_performance_data_analysis.ipynb` – Jupyter Notebook containing the complete analysis and visualizations.
* `student-mat.csv` – Dataset used for the analysis.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
